# BCSFE Android

简体中文 | [English](README.md)

这是一个面向《猫咪大战争》的 Android 存档编辑器。应用使用 Java 编写，界面采用 Android XML 布局与资源。英文文案位于 `app/src/main/res/values/strings.xml`，简体中文文案位于 `app/src/main/res/values-zh-rCN/strings.xml`，后续可以继续通过 Android 资源限定符增加其他语言，无需修改应用逻辑。

## 当前状态

Android 版已经覆盖 BCSFE 的主要编辑功能，包括基础货币与券、猫咪／形态／本能／储藏库、主线与活动关卡、发掘关卡与强袭、加码多多／城堡开发队／猫咪神社、账号凭据、抽卡种子、修复项目、编队、抽奖活动、图鉴、任务、勋章、黄金会员及相关道具。

目前支持导入与导出存档、接收转移码、上传存档并生成新转移码、创建替代账号，以及独立上传受管理道具。导入时会验证文件格式；其他 Android 应用分享过来的文件也可以直接作为一个新会话打开。

格式核心会验证并重写不同地区使用的 MD5 校验值，同时保留未知数据。当前深度编辑功能以 JP、EN、TW 和 KR 的 15.5 存档为目标。15.5 地区转换经过逐字节测试；版本转换支持 14.0、14.3 至 15.5，并处理不同版本的道场、发掘关卡及尾部记录布局。

编辑器采用分层导航：先选择“基础信息”等分类，再选择猫罐头、XP 等具体功能。可以在“关于”页面明确切换英文或简体中文。

导入、接收转移存档以及每次编辑后，当前工作存档都会原子写入应用私有存储。即使上传、结束进程、退出应用或重启设备，会话也会保留，直到用户确认删除。左侧会话栏可以同时保存多个独立工作存档，并支持切换、重命名和删除。

当前版本的 offsets 未必适合每个人的使用场景，因此本仓库不提供 offsets。构建前请根据空白的 `.env.example` 在本地创建并填写私有 `.env`，避免公开快速过时并可能误导用户的数值。

## 构建

可以在 Android Studio 中打开仓库并运行 `app` 配置，也可以使用 Gradle 8.x：

```sh
gradle assembleDebug
```

项目要求 Android SDK 34 或更高版本，以及 Java 17。

## 验证状态

- JVM 测试覆盖地区校验值、持久化会话、道具／猫咪／账号编辑器、可变长度数据表、游戏版本与地区转换，以及固定协议签名向量。
- 主要关卡类型都与 BCSFE-Python 生成的存档进行逐字节对比，包括活动、挑战、强袭、发掘关卡、传奇任务、异界塔、零传奇和猫爪道场。
- TW 15.5.0 转移存档已从正式转移接口接收，经过有效校验并通过 Android 模拟器的系统文件选择器导入。
- Debug APK 已在 Android 模拟器中使用两种语言进行验证，包括强制停止后恢复会话、退出确认、分类导航、猫咪数据重置确认及相关关卡编辑流程。

转移凭据和下载的测试存档不会保存在本仓库中，也不会写入应用日志。
